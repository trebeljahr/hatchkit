An open documentation tab can outlive the container that served it. This site keeps older files so navigation still works after a release.

The production site at [hatchkit.trebeljahr.com](https://hatchkit.trebeljahr.com) runs as a Docker Image application in Coolify.
Next.js exports the pages during the build. nginx serves those files without a Node server.

## Release a new version

The [release workflow](https://github.com/trebeljahr/hatchkit/blob/main/.github/workflows/deploy.yml) builds an image tagged with the full source commit.
A build does not move the serving `latest` tag.

Before the build, the workflow verifies the current public version and its registry journal.
It pins that image by digest and retains its exported files.
An existing commit tag cannot be rebuilt with different inputs.
The build artifact records the new digest and its parent image.

Deployment checks that the parent still matches the serving baseline.
It then promotes the candidate and queues one deployment of this site.
The public version and HTML must report the new commit throughout the verification window.
An uncertain queue result stops further automatic releases until an operator checks the exact deployment.

The repository variable `HATCHKIT_ROLLOUT_MODE` controls activation:

| Value | Behavior |
| --- | --- |
| Unset or `off` | Build images without deploying them. |
| `manual` | Deploy an explicitly reviewed commit and digest. |
| `automatic` | Deploy successful main-branch builds through the same checks. |

## Keep open tabs usable

Each image contains the current export and up to two prior exports.
Next.js attaches its deployment ID to page-data requests.
nginx uses that ID to serve the matching export, including its older JavaScript chunks.
An invalid ID fails without selecting another directory.

Tabs outside the retained window reload their current URL.
The URL keeps its query and fragment.
This policy suits documentation pages. Editors and games need durable user state before they can use the same policy.

## Drain the retiring container

On SIGTERM, the entrypoint makes the local health probe fail while public requests continue.
It waits 20 seconds before asking nginx to exit.
Coolify's health checks and proxy removal must fit inside that interval.
The host must provide a stop deadline longer than the drain.

Test the exact host behavior during adoption. A health check alone does not prove uninterrupted traffic or graceful shutdown.

## Build the static export locally

Run these commands from `docs/`:

```bash
pnpm install
pnpm build
```

The output is `docs/out/`. A standalone export can run on a static host.
The retained-release routing described here requires the repository's nginx image.
For a separate GitHub Pages setup, see [the `gh-pages` reference](./gh-pages).
